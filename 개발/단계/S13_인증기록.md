## AI 지시

```text
[작업] 인증 기록 화면을 만든다. (S13)

[먼저 읽기] AGENTS.md, 개발/연결명세.md 의 §2-2, §3-3, 기획서/환경이_기획서_복붙용.md 의 "주요 화면" ⑥

- 날짜별로 묶어서 한 줄씩: 미션 이름(빈 그릇 / 친환경 제품 / 환경 문구), 결과, 얻은 점수, 그때 점수(score_after), 작은 사진(서명 URL 60초)
- 기록이 없으면 "아직 인증 기록이 없어요" 안내

[규칙] 읽기만 한다 (DB에 쓰지 않음). 3D 마을 관련 파일(frontend/src/village.js·config.js·scene/·world/·character/·behaviors/·states/·ui/)은 고치지 않는다. git 명령 실행 금지.

[끝나면] 확인 순서를 알려주고 멈춘다.
```
