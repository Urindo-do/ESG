**끝나면**: 홈을 열면 서버가 **감소까지 반영한 지금 점수**와 남은 횟수를 알려준다. 시연용 「시간 경과」 버튼으로 며칠이 지난 모습(꼬질꼬질)을 보여 줄 수 있다.

## 사람이 먼저 할 일

## AI 지시

```text
[작업] get-status 함수를 만들고, 홈 화면이 실제 상태(감소 반영)를 쓰게 한다. 시연용 시간 경과 버튼을 만든다. (S11)

[먼저 읽기] AGENTS.md, 개발/연결명세.md 의 §0-1(DEMO_MODE), §1-1, §3-2, 그리고 supabase/functions/_shared/rules.ts

[만들거나 고칠 파일]
1. supabase/functions/get-status/index.ts — 명세 §3-2. 감소·남은 횟수는 rules.ts 함수로 계산. simulateHours는 비밀값 DEMO_MODE가 "true"일 때만 반영하고 저장하지 않는다.
2. frontend/src/app/api.js — REAL 전환표에서 status를 true.
3. frontend/src/app/screens/home.js — 홈을 열 때 getStatus로 닉네임·점수·남은 횟수를 표시 (S3의 "// 임시" 두 곳 제거).
4. 시연용 「시간 경과」 버튼 — 주소 끝에 ?demo=1 이 있을 때만 보인다. 누르면 몇 시간이 지난 것으로 볼지 입력받아 getStatus({ simulateHours })를 부르고, 받은 점수로 setCleanliness.

[규칙] git 명령 실행 금지.

[끝나면] 배포 명령, 비밀값 설정, 확인 순서를 알려주고 멈춘다.
```

## AI가 끝난 뒤 사람이 할 일

1. 배포
   ```
   npx supabase functions deploy get-status --use-api
   ```
2. 대시보드 Edge Functions의 Secrets에 `DEMO_MODE` = `true` 추가 (시연이 끝나면 지워도 됨)

## 확인

- [ ] 홈을 열 때 get-status가 불린다 (대시보드 get-status Logs에 기록)
- [ ] 방금 인증해서 점수가 60인 계정 → 주소 끝에 `?demo=1` → 「시간 경과」에 `72` 입력 → **40 · '보통'** (명세 §1-1 표)
- [ ] 점수 71인 계정 → `120` 입력 → **31 · '꼬질꼬질'** (시연 시나리오 ⑤와 같은 계산)
- [ ] `?demo=1` 없이 열면 버튼이 안 보인다
- [ ] 새로고침하면 원래 점수로 돌아온다 (시연용 시간은 저장되지 않음)
