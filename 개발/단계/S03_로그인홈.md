| 예상 | 난이도 | 앞 단계 |
|---|---|---|
| 60분 | ★★☆ | S2 |

**끝나면**: 회원가입·로그인을 하면 홈에 닉네임과 점수 50·'보통'이 보인다. 브라우저에서 점수를 몰래 바꾸려 해도 바뀌지 않는다.

## 사람이 먼저 할 일

1. 받기 ([체크리스트 §2](../체크리스트.md#2-받기--매번-시작할-때))
2. `frontend/.env.local` 파일 만들기 — S0에서 메모한 두 값을 넣는다 (AI에게 "이 두 값으로 frontend/.env.local을 만들어줘"라고 해도 된다)
   ```
   VITE_SUPABASE_URL=https://프로젝트주소.supabase.co
   VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_로시작하는값
   ```
   - ⚠️ **공개 키만.** `sb_secret_…`·`service_role`은 넣지도, AI에게 보여주지도 않는다
   - 이 파일은 `.gitignore`에 걸려서 올라가지 않는다

## 확인

`frontend` 폴더에서 `npm run dev` (`.env.local`을 만들거나 고쳤으면 서버를 껐다 켠다)

- [ ] 처음 쓰는 이메일로 가입 → 바로 홈으로 가고, 닉네임·점수 50·'보통'이 보인다
- [ ] 새로고침해도 로그인이 유지되고, 로그아웃하면 로그인 화면이 나온다
- [ ] 대시보드 Table Editor의 `profiles`에 새 행이 있고 닉네임이 입력한 값이다
- [ ] **점수 조작이 막힌다** — 로그인한 상태에서 `F12` → Console에 아래 한 줄을 붙여넣고 Enter
  ```
  const { data: { user } } = await __supabase.auth.getUser(); await __supabase.from('profiles').update({ score: 100 }).eq('id', user.id).select();
  ```
  → 결과의 `data`가 **빈 배열 `[]`** 이고, 새로고침해도 점수가 **50 그대로**다
  (크롬이 붙여넣기를 막으면 Console에 `allow pasting`을 입력하고 다시 붙여넣는다)
- [ ] **남의 정보가 안 보인다** — 다른 이메일로도 하나 가입해 둔 뒤, Console에 `await __supabase.from('profiles').select()` → **내 행 1개만** 나온다
- [ ] 휴대폰 — 노트북과 같은 와이파이에서 `npm run dev -- --host` → 터미널의 Network 주소로 접속하면 로그인 화면이 보인다

## 막히면

- `Invalid API key` → `.env.local` 값 확인 후 서버 재시작
- `Email not confirmed` → S2의 Confirm email 끄기 확인
- `Database error saving new user` → S2 트리거 확인
- 점수 조작이 **성공**해 버린다 → 멈추고 S2의 RLS 정책을 다시 본다 (update 정책이 있으면 안 됨)
