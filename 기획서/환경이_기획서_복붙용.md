## 2. 문제 정의

### 칸: 제안 배경 및 필요성

**기후위기 인식은 커졌지만 실천 의지는 줄고 있음**
• 기후변화를 가장 중요한 환경문제로 꼽은 응답: 2021년 39.8% → 2024년 68.2%
• "불편하더라도 환경친화적 행동을 우선한다" 응답: 2018년 70.5% → 2024년 58.4%
• 20대는 친환경 행동이 어려운 가장 큰 이유로 '비용이 많이 든다'를 꼽음
  (출처: 한국환경연구원, 2024 국민환경의식조사)
**실천을 이어가게 할 즉각적인 보상과 피드백이 부족함**
• 잔반 남기지 않기, 인증 제품 고르기 같은 작은 실천은 효과가 눈에 보이지 않아 동기가 쉽게 끊김
• 기존 보상 제도는 제휴 매장·기업 앱·전용 측정기가 있어야 적립되어, 일상 어디서나 바로 인증하기 어려움
→ 비용이 들지 않는 일상 실천을 사진 한 장으로 인증하고, 그 결과를 캐릭터의 변화로 바로 보여주는 서비스가 필요함

### 칸: 타깃 대상

**주 타깃: 10~20대 (대학생·사회초년생)**
• 환경 문제에 공감하지만 비용·번거로움 때문에 실천이 꾸준하지 않은 층
• 캐릭터 육성 게임과 SNS 공유에 익숙해 게임형 보상에 반응하고, 자발적 확산을 기대할 수 있음
**페르소나 (예시)**
• 자취하는 대학생 김지우(22세): 학식·배달·편의점으로 식사를 해결함. 환경 뉴스에는 공감하지만 "나 하나 바꾼다고 달라질까" 싶어 실천이 며칠을 못 감. 돈이 더 드는 친환경 제품은 부담스럽고, 매일 들어가 확인하는 캐릭터 게임은 즐김.

### 칸: 유사 제품 현황 및 비교

**탄소중립포인트 녹색생활실천 (기후에너지환경부·한국환경산업기술원)**
• 잔반제로 실천·친환경제품 구매·다회용기 등 17개 항목에 현금성 포인트 지급
• 한계: 참여 기업 앱 연동, 스마트 잔반 측정기를 설치한 식당 등 제휴처에서만 적립됨
**경기도 기후행동 기회소득**
• 교통·에너지·자원순환·인식제고 15개 활동에 지역화폐 등 지급
• 한계: 경기도 거주자 중심, 데이터 자동 연계 위주
**앤트 포레스트 (중국 알리페이)**
• 저탄소 행동으로 가상 나무를 키우면 실제 나무를 심어주는 게임형 서비스. 약 5억 명 참여, 약 1억 2,200만 그루 식재 (2019 UN 지구환경대상 수상)
**환경이의 차별점**
• 제휴처·측정기 없이 어디서나 사진 한 장으로 인증
• 현금 대신 캐릭터 상태 변화로 즉시 피드백. 실천을 멈추면 캐릭터가 더러워지는 '돌봄' 구조로 재방문 유도
• 친환경 제품은 공식 인증 DB(환경표지·환경성적표지)와 대조해 확인된 제품만 인정
• 지역 제한 없음

### 칸: 문제의 심각성 / 근거

**음식물쓰레기**
• 한국의 1인당 가정 음식물쓰레기는 연 95kg으로 세계 평균(79kg)보다 많음
• 2022년 전 세계에서 버려진 식품은 약 10억 5천만 톤으로 생산량의 약 19%
  (출처: UNEP, Food Waste Index Report 2024)
• 개인별 잔반 측정·포인트를 도입한 경기도 북부청사 구내식당에서 월평균 잔반량이 17.7% 감소함 → 기록과 보상이 실제 행동을 바꿀 수 있음 (경기도, 2025.9.)
**인식과 실천의 격차**
• "나의 참여가 환경 문제를 개선할 수 있다" 56.6%, 친환경 제품에 돈을 더 낼 의향 37.2% (대학내일20대연구소, 2025.6., 15~49세 500명)
• 20대는 비용 부담을 친환경 행동의 가장 큰 장벽으로 인식 (한국환경연구원, 2024)
**친환경 제품 정보**
• 환경성적표지 인증 제품만 3,189개(653개 기업, 저탄소제품 1,527개 포함, 2025.12.31. 기준)가 공개되어 있으나, 소비자가 산 제품의 인증 여부를 확인하려면 별도 사이트에서 직접 검색해야 함

## 3. 아이디어 개요

### 칸: 아이디어명

환경이 (가칭)

### 칸: 한 줄 요약

빈 그릇·친환경 제품·환경 문구를 사진으로 인증하면 캐릭터 '환경이'가 깨끗해지고, 실천을 멈추면 다시 꼬질꼬질해지는 게임형 환경 습관 서비스

### 칸: 핵심 컨셉 설명

**"돌봐야 깨끗해지는" 다마고치형 환경 습관 앱**
• 레벨 대신 청결 점수(0~100)에 따라 환경이의 모습과 숲 마을 풍경이 5단계로 바뀜
• 마지막 인증 후 48시간이 지나면 점수가 조금씩 떨어져 환경이가 꼬질꼬질해짐 → 매일 들어올 이유를 만듦
**AI는 판정, 점수는 코드**
• 사진 판정(빈 그릇 여부, 제품명·인증마크 읽기, 환경 문구 여부)은 멀티모달 AI가 수행
• 점수 계산·하루 제한·중복 사진 차단은 정해진 규칙 코드가 수행해 AI가 점수를 임의로 만들지 않음
**캐릭터**
• 도토리 모자와 나뭇가지 뿔, 나뭇잎 옷을 입은 숲의 정령 '환경이'가 3D 숲 마을에서 물 주기·씨앗 심기·낙엽 쓸기 같은 일상을 보냄

## 4. 문제 해결 방안

### 칸: 핵심 기능 (3가지 이내)

**① 잔반 제로 인증**
• 식사를 마친 빈 그릇 사진 1장 → AI가 남은 음식이 있는지 판정 → 완전히 비웠으면 +10점 (하루 3회)
**② 친환경 제품 인증**
• 구매한 제품 포장 사진 → AI가 제품명·브랜드·용량·인증마크를 읽음 → 환경표지·환경성적표지(저탄소제품 포함) 공식 인증 DB와 대조 → 등록 제품이면 +10점, 없으면 0점과 "공식 인증 정보 없음" 안내 (하루 2개, 같은 사진 재사용 불가)
**③ 환경 문구 찾기**
• 거리·건물의 환경 캠페인 문구나 직접 쓴 다짐 사진 → AI가 환경 관련 문구인지 판정 → +1점 (기준 점수의 0.1배, 하루 10개, 중복 허용)
※ 공통: 얻은 점수는 환경이의 청결 점수에 반영되고, 48시간 동안 인증이 없으면 점수가 줄어듦

### 칸: 활용 AI 기술 / 데이터

**AI 기술**
• 멀티모달 LLM(Vision): 빈 그릇 판정 / 제품 포장의 글자·인증마크 인식(OCR) / 환경 문구 판정. 결과는 정해진 JSON 형식(판정·확신도·읽은 글자·이유)으로만 받음
• 제품명 매칭: 읽어낸 제품명·업체명을 인증 DB에서 유사도 검색(Postgres pg_trgm)으로 찾고, 후보가 여러 개면 사용자가 선택
• 규칙 코드: 점수 계산, 하루 제한, 이미지 해시로 중복 사진 차단, 점수 감소
**데이터 (실제 공공데이터)**
• 환경성적표지 유효 인증현황 – 기후에너지환경부·한국환경산업기술원 (2025.12.31. 기준 3,189개 제품: 인증 종류·인증번호·기업명·제품명·유효기간)
• 환경표지 인증내역 – 한국환경산업기술원 (제품명·모델명·업체명·인증번호·인증기간)
• (향후) 바코드 상품정보 – 유통물류진흥원 코리안넷 (B2B 제휴 필요)

### 칸: 서비스 이용 흐름

1) 회원가입·로그인
2) 홈(환경이 마을): 청결 점수, 환경이 상태, 오늘 남은 인증 횟수 확인
3) 미션 선택: 빈 그릇 / 친환경 제품 / 환경 문구
4) 카메라 촬영 (미션별 촬영 가이드 제공)
5) AI 판정 → 결과 카드 (제품 후보가 여럿이면 "이 제품이 맞나요?" 선택)
6) 점수 반영 → 환경이가 깨끗해지는 연출
7) 인증 기록에서 날짜별 실천 내역과 점수 변화 확인

## 5. 기대효과 및 사회적 가치

### 칸: (표 한 칸)

**개인 – 돈이 들지 않는 실천의 습관화**
• 20대가 꼽은 가장 큰 장벽인 비용 부담 없이, 잔반 줄이기·인증 제품 고르기·캠페인 문구 발견 같은 일상 행동에 즉각적인 보상을 줌
**환경 – 음식물쓰레기 감소**
• 빈 그릇 인증으로 끼니마다 '남기지 않기'를 의식하게 함. 기록과 보상이 잔반을 줄인 구내식당 사례의 구조를 측정기 없이 가정·학식·외식으로 넓힘
**시장 – 공식 인증 제품의 인지도 향상**
• 사용자가 직접 산 제품의 인증 여부를 확인하면서 환경표지·환경성적표지를 알게 되고, 인증에 투자한 기업의 제품이 선택받는 신호가 됨
**사회 – 자발적 확산과 인식 개선**
• 캐릭터를 키우는 구조는 앤트 포레스트(약 5억 명 참여)처럼 대규모 참여를 이끈 방식이며, 캐릭터 상태 공유로 10~20대 사이 확산을 노림
• 환경 문구 찾기로 주변의 환경 캠페인을 한 번 더 읽게 함
**확장 – 기존 제도와 연계**
• 인증 기록을 탄소중립포인트 등 공공 보상 제도와 연계하는 방안을 향후 검토

## 6. 실현 가능성

### 칸: 필요 기술 / 리소스

• 프론트엔드: Vite + Three.js (3D 캐릭터·숲 마을), 모바일 웹 카메라 촬영
• 백엔드: Supabase – Auth(회원가입·로그인), Postgres(사용자·인증 기록·점수·인증 제품 DB), Storage(인증 사진), Edge Functions(AI API 호출·점수 계산, API 키 서버 보관)
• AI: 멀티모달 LLM API
• 데이터: Python·Pandas로 인증 데이터 전처리 후 Supabase 테이블에 적재
• 리소스: 환경이 캐릭터 콘셉트 이미지(확보), 청결 단계별 3D 표현(텍스처·파티클)

### 칸: 예상 제약 / 리스크

① 바코드 상품정보 API(코리안넷)는 유료 B2B 제휴(최소 12개월 계약)라 MVP에서 쓸 수 없고, 식약처 바코드 API는 2018년 이후 갱신이 중단됨
② 인증 DB에 바코드 정보가 없어 제품 사진과 인증 DB의 자동 연결이 틀릴 수 있음
③ 빈 그릇 사진만으로는 본인이 먹었는지 확인할 수 없음 (다른 사람 그릇·예전 사진)
④ AI 판정 오류(잔반·문구 오판)와 API 호출 비용
⑤ 3D 그래픽의 구현 난이도와 모바일 성능
⑥ 점수 감소가 너무 빠르면 사용자가 이탈할 수 있음

### 칸: 극복 방안

① 바코드·QR 연동은 향후 계획으로 두고, MVP는 제품 포장 사진의 글자·인증마크 인식으로 제품을 찾음
② 유사도가 기준에 못 미치면 후보를 보여주고 사용자가 고르게 함. 끝내 못 찾으면 0점과 "공식 인증 정보 없음" 안내 (미등록이 곧 친환경이 아니라는 뜻은 아님)
③ 앱 안의 카메라로만 촬영(갤러리 업로드 제한), 이미지 해시로 같은 사진 재사용 차단, 하루 횟수 제한, 애매하면 '완전히 비운 경우'만 인정. 완벽한 검증보다 사용 편의와 신뢰의 균형을 목표로 함
④ AI 출력 형식을 고정하고 확신도가 낮으면 점수 없이 재촬영 안내, 1인 하루 인증 상한으로 호출량 제한
⑤ 둥근 저폴리 스타일로 모델을 단순화하고, 청결 단계는 텍스처·파티클 교체로 표현
⑥ 감소 시작 시점(48시간)과 감소량을 설정값으로 분리해 시연하며 조절하고, '꼬질꼬질' 전에 중간 단계를 둠

## 7. MVP 설계서

### 칸: (표 한 칸)

**1. MVP 목표**
• "로그인 → 미션 사진 인증 → AI 판정 → 점수 반영 → 환경이 상태 변화"를 처음부터 끝까지 시연
**2. 포함 범위**
• 이메일 회원가입·로그인 (Supabase Auth)
• 환경이 3D 숲 마을 홈 화면 + 청결 점수 5단계 표현
• 미션 3종 선택 → 카메라 촬영 → AI 판정 → 결과 카드
• 친환경 제품: 환경성적표지·환경표지 인증 DB 대조
• 점수 규칙: 하루 제한, 중복 사진 차단, 48시간 후 점수 감소
• 인증 기록 화면
**3. 제외 범위 (향후 계획)**
• 바코드·QR 상품정보 연동 (코리안넷 B2B 제휴, GS1 QR)
• 실제 구매·분리배출 행동을 환경이의 동작 애니메이션으로 재현
• 영수증 인증, 친구·랭킹·SNS 공유, 탄소중립포인트 연계, 친환경 농산물 인증 DB
**4. 점수 규칙 (초안 – 시연하며 조절)**
• 빈 그릇 +10점 (하루 3회) / 친환경 제품 +10점, 미확인 0점 (하루 2개) / 환경 문구 +1점 (하루 10개)
• 청결 점수 0~100 (상한 100). 마지막 인증 후 48시간이 지나면 24시간마다 -10점
• 상태 5단계: 반짝반짝(80~100) · 깨끗(60~79) · 보통(40~59) · 꼬질꼬질(20~39) · 먼지투성이(0~19)
**5. 시스템 구성**
• 웹(Vite + Three.js) → Supabase Edge Function → 멀티모달 LLM API
• Edge Function에서 인증 DB 조회·점수 계산 → Supabase Postgres·Storage에 저장 → 웹에 결과 반환
• 전체 구성도: 첨부 그림 「환경이 AI 아키텍처」 참고
**6. 데이터 구조 (Supabase)**
• profiles: 사용자 ID, 닉네임, 청결 점수, 마지막 인증 시각
• missions: 사용자 ID, 미션 종류, 사진 경로, 이미지 해시, AI 판정 결과, 얻은 점수, 인증 시각
• eco_products: 인증 종류(환경표지/환경성적/저탄소제품), 인증번호, 업체명, 제품명, 인증 시작·종료일
**7. 시연 시나리오**
① 빈 그릇 촬영 → +10점, 환경이가 깨끗해짐
② 저탄소제품 인증 생수(예: 아이시스ECO 500mL, 인증번호 2024-240) 촬영 → 인증 정보 카드와 +10점
③ 인증 정보가 없는 과자 촬영 → 0점, "공식 인증 정보 없음" 안내
④ 환경 캠페인 배너 촬영 → +1점
⑤ 시간 경과(시연용 테스트 기능) → 점수 감소, 환경이가 꼬질꼬질해짐

## 8. 요구사항정의서 (8-2) 주요 화면 및 사용자 흐름

### 칸: (표 한 칸)

**주요 화면**
① 로그인·회원가입: 이메일·비밀번호, 닉네임
② 홈(환경이 마을): 3D 숲 마을 속 환경이, 상단 청결 점수 게이지와 상태 이름, 오늘 남은 인증 횟수, 하단 미션 버튼 3개(「빈 그릇 인증」「친환경 제품 인증」「환경 문구 찾기」), 시점 회전·확대와 「카메라 초기화」
③ 촬영: 미션별 촬영 가이드(예: "그릇 전체가 보이게 찍어주세요"), 촬영 → 미리보기 → 「인증하기」
④ 판정 결과: 판정 문구, 근거(인증 종류·인증번호·유효기간 등), 얻은 점수, "AI 판정은 틀릴 수 있어요" 안내와 「다시 찍기」
⑤ 상태 변화 연출: 점수가 오르면 반짝임과 꽃이 피어나고, 점수가 떨어지면 먼지와 시든 풀이 나타남
⑥ 인증 기록: 날짜별 인증 내역과 점수 변화
**사용자 흐름**
로그인 → 홈 → 미션 선택 → 촬영 → AI 판정 → (제품 후보 선택) → 점수 반영 → 홈에서 환경이 변화 확인 → 인증 기록
**환경이의 평소 모습 (자동 행동)**
• 물뿌리개로 꽃에 물 주기, 씨앗 심기, 낙엽 쓸기, 나비 구경하기, 개울가 산책, 나무 그늘에서 낮잠
• 청결 점수가 낮으면 시무룩하게 앉아 몸의 먼지를 털어냄
**디자인 방향**
• 둥근 2~3등신 캐릭터, 따뜻한 햇살과 부드러운 그림자, 초록·연두·나무색 계열, 한글 UI와 둥근 카드

## 8. 요구사항정의서 (8-3) AI 및 데이터 구현 계획

### 칸: AI 모델

• 멀티모달 LLM(Vision) API 1종에 미션별 프롬프트 3개 적용
  ① 잔반 판정: 판정(다 먹음/남음/판정 불가), 확신도, 이유
  ② 제품 인식: 제품명, 브랜드, 용량, 인증마크 종류, 확신도
  ③ 문구 판정: 읽은 문구, 환경 관련 여부, 확신도
• 모든 응답은 JSON 형식으로 고정하고, 확신도가 기준보다 낮으면 점수 없이 재촬영 안내

### 칸: 데이터

• 환경성적표지 유효 인증현황 (기후에너지환경부·한국환경산업기술원, 2025.12.31. 기준 3,189개 제품) – 공공데이터포털 최신본(2026.7. 갱신) 반영 예정, 이용허락 제한 없음
• 환경표지 인증내역 (한국환경산업기술원) – 제품명·모델명·업체명·인증번호·인증기간
• 전처리(Python·Pandas): 유효기간이 지난 인증 제외, 인증 종류(환경표지/환경성적/저탄소제품) 표준화, 검색용 제품명(공백·괄호·용량 표기 정리) 생성 → Supabase eco_products 테이블 적재
• 사용자 데이터: 이메일, 닉네임, 인증 사진, 판정 결과, 점수 기록

### 칸: 외부 서비스

• Supabase: Auth(로그인), Postgres(데이터 저장·pg_trgm 유사도 검색), Storage(사진), Edge Functions(AI 호출·점수 계산)

### 칸: 구현도구

• Vite, Three.js, JavaScript

• Python, Pandas (데이터 전처리)

## 9. 안전·윤리·사용성 점검

### 칸: 데이터 및 개인정보

■ 주민등록번호, 전화번호, 주소 등 불필요한 개인정보를 입력받지 않는다. 
■ 개인정보가 필요한 경우 최소한의 정보만 사용한다. 
■ 실제 개인정보 대신 예시 또는 가상 데이터를 사용한다. 
□ 사용 데이터의 출처와 사용 가능 여부를 확인했다. 
■ API 키나 비밀번호가 화면 또는 코드에 노출되지 않는다
→ 로그인은 이메일·닉네임만 사용하고, 시연은 테스트 계정으로 진행
→ AI API 키는 Supabase Edge Function의 서버 환경변수에만 보관
→ 인증 사진은 본인만 볼 수 있게 저장(행 단위 보안 정책)하고, 사람 얼굴이 찍히지 않도록 촬영 가이드 제공

### 칸: AI 안전·윤리

■ AI 결과를 정답이나 사실로 단정하지 않는다. 
■ 잘못된 결과가 나올 수 있음을 사용자에게 안내한다. 
■ 특정 집단에 불리한 편향이 발생할 가능성을 검토했다. 
■ 의료·법률·금융 등 중요한 판단을AI가 단독으로 결정하지 않는다.
→ 결과 카드에 "AI 판정은 틀릴 수 있어요" 표시와 「다시 찍기」 제공
→ 인증 DB에 없는 제품은 "친환경이 아님"이 아니라 "공식 인증 정보 없음"으로 안내
→ 국물·소스 요리처럼 음식 종류에 따라 잔반 판정이 불리하지 않은지 시연 전 점검
→ AI 판정은 게임 점수에만 쓰고 다른 중요한 판단에는 쓰지 않음

### 칸: 사용성 / 접근성

■ 사용자가 무엇을 입력해야 하는지 쉽게 이해할 수 있다. 
■ 결과가 전문용어 없이 이해하기 쉽게 제공된다. 
■ 오류가 발생했을 때 안내 메시지가 제공된다. 
■ 샘플 입력으로 핵심 흐름을 처음부터 끝까지 시연할 수 있다.
→ 미션별 촬영 가이드 문구 제공, 결과는 "다 먹었어요!"처럼 쉬운 말로 표시
→ 판정 실패·네트워크 오류 시 다시 시도 안내
→ 시연 시나리오 5개로 전체 흐름 시연
