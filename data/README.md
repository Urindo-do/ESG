## 환경성적표지 xlsx 구조 (S8에서 사용)

- 사용할 시트: `유효인증현황(12.31.)` (나머지 상호인정 MRA 시트 2개는 쓰지 않음)
- **6행이 머리글, 7행부터 데이터.** 위쪽 병합 머리글 때문에 Pandas가 붙이는 열 이름이 꼬이므로 **열 위치로 고른다**

| 열 | 머리글 | 쓰임 |
|---|---|---|
| B | 기업명 | `company` |
| D | 영향범주 (`환경성적` / `저탄소제품`) | `cert_type` |
| F | 인증번호 | `cert_no` |
| H | 인증제품명 | `product_name`, `search_name` |
| AZ | 시작 | `valid_from` |
| BA | 종료 | `valid_to` |

- 행 수 (2026-09-17, 코드로 셈): 전체 **3,189** (환경성적 1,662 · 저탄소제품 1,527) → 9/17 기준 유효 **2,829** (환경성적 1,437 · 저탄소제품 1,392)
- 시연 제품 행: `저탄소제품 · 2024-240 · 롯데칠성음료 (주) · 아이시스ECO[500mL,PET] · 2024-04-25 ~ 2027-04-24`
- `아이시스`가 들어간 유효 제품은 7개 → 검색어에 용량·ECO까지 있어야 위 행이 1순위가 된다
