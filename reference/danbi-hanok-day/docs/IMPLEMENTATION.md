# 구현 기록

## 기준과 범위

- 사용자 제공 명세를 바탕으로 현재 폴더에 새로운 Three.js + Vite 프로젝트를 작성했습니다.
- 참조 URL: https://danbi-hanok-day.dantelabs.chatgpt.site/
- 해당 URL의 원본 소스를 확보하지 못했으므로 기존 사이트의 정확한 복제본은 아닙니다.
- 로컬 저장과 실행이 이번 작업의 범위입니다.

## 구현한 항목

- 2~3두신 크림빛 진돗개: 삼각 귀, 검은 코, 둥근 눈, 볼의 털 뭉치, 말린 꼬리
- 연하늘색 한복 조끼: 겹치는 깃, 작은 고름, 노란 목수건
- 단면 한옥: 온돌방, 툇마루, 계단, 나무 기둥·서까래, 격자 한지 창호, 뒷부분 기와지붕
- 한지 패널의 반투명 재질, 절차적 목재·한지 질감, 오후 방향광과 실내등, 그림자
- 보료, 낮잠 방석, 쿠션, 낮은 밥상, 도자기 식기, 책장, 장난감 상자, 빗자루와 쓰레받기, 창가 화분, 라디오, 공, 개껌 바구니
- 마당의 장독대, 작은 평상, 화초, 돌길, 돌담
- 밥 먹기, 물 마시기, 공놀이, 책 구경, 낮잠, 마당 산책, 정리, 창밖 구경, 몸 털기, 냄새 맡기
- 귀 움직임, 눈 깜박임, 꼬리 흔들기, 고개 갸웃, 앞발 동작, 냄새 맡는 자세, 하품, 졸음
- 무작위 자동 행동, 수동 행동 선택, 일시 정지·재개, 선택 시 즉시 전환
- 가구 클릭 및 터치, 시점 회전·확대·축소·초기화
- 한글 UI, 반응형 배치, 키보드 조작 가능한 행동 버튼, 동작 줄이기 설정 존중
- 가구를 피하는 경로 탐색, 앞 계단을 통한 실내외 이동
- HMR 종료 시 렌더러·재질·텍스처·이벤트 제어기 정리
- 움직이지 않는 한옥 메시를 재질별로 병합해 렌더링 호출 감소

## 표현상의 제한

- 자체 제작한 절차적 모델입니다. 별도 리깅 에셋, 실시간 털, 물리 기반 집기 동작은 포함하지 않습니다.
- 창호는 미닫이문 형태의 고정 패널입니다. 문을 직접 여닫는 조작은 구현하지 않았습니다.
- 방석·보료는 같은 낮잠 행동, 창가 비품은 같은 창밖 구경 행동으로 연결됩니다.
- 라디오는 장식과 창가 행동의 클릭 대상이며 소리를 재생하지 않습니다.
- 자동 테스트는 경로와 행동 상태를 검증합니다. 시각적 품질이나 모든 장치의 WebGL 성능을 보증하지 않습니다.

## 검증 기록

- `npm.cmd install`: 성공, 설치 시 npm audit 취약점 0건
- `npm.cmd test`: 5개 검사 통과. 모든 행동 간 경로, 계단 높이, 일시 정지, 수동 완료·자동 전환, 열 가지 행동의 종료 확인
- `npm.cmd run build`: 성공, `dist/` 생성
- `npm.cmd run dev -- --port 5173 --strictPort`: 개발 서버 시작 성공
- `http://127.0.0.1:5173/`: HTTP 200 응답 확인
- Three.js 번들이 Vite의 기본 500 kB 알림 기준을 조금 초과합니다. 빌드 오류는 아니며 엔진 번들을 별도 파일로 분리했습니다.
- 실제 브라우저의 화면·터치·HMR 동작은 이번 작업에서 직접 검증하지 않았습니다.

검사 과정에서 산책 종료 시 미완료 경로가 남는 문제를 발견해 수정했습니다. 수동 행동이 끝난 뒤 ‘다시 시작’을 누르면 그 행동을 처음부터 실행하도록 처리했습니다.
