**무슨 일이 있었나**: 원래 계획은 이 단계에서 가벼운 "2D 대역 마을"을 먼저 만들고, 3D는 S12에서 나중에 붙이는 것이었다. 그런데 팀원이 3D 데이터 작업을 하다가 [S12](S12_3D마을.md)의 3D 마을(로그인·카메라 빼고) 전체를 먼저 완성해서 가져왔다. 그래서 이 단계와 S12가 한 번에 끝났고, 2D 대역은 만들지 않기로 했다.

**지금 상태**: `frontend/`에 실제로 동작하는 Vite 프로젝트가 있다. `npm install` → `npm run dev` → `http://localhost:5173/`에서 3D 환경이 마을이 뜬다. 자세한 실행법·연결 방법·파일 구조는 [`frontend/README.md`](../../frontend/README.md) 참고.
