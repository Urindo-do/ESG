# 단비의 하루

크림빛 아기 진돗개 단비가 작은 한옥에서 보내는 하루를 담은 Three.js + Vite 생활형 3D 웹 앱입니다.
이 폴더의 코드는 제공된 프롬프트를 바탕으로 새로 구현했습니다. 링크에 배포된 사이트의 소스를 내려받은 사본은 아닙니다.

## 실행

Node.js 22.12 이상을 설치한 뒤, 이 폴더에서 실행합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

터미널에 나오는 로컬 주소(기본 `http://127.0.0.1:5173`)를 엽니다. 파일을 수정하면 Vite가 즉시 반영합니다.
Windows PowerShell 실행 정책으로 `npm.ps1`이 차단될 때도 `npm.cmd` 명령은 사용할 수 있습니다.
의존성이 설치되어 있으면 다음부터는 `npm.cmd run dev`만 실행하면 됩니다.

```powershell
npm.cmd run build    # 배포 가능한 정적 파일을 dist/에 생성
npm.cmd run preview  # 빌드 결과를 로컬에서 실행
npm.cmd test         # 이동 경로 및 행동 상태 검증
```

`index.html` 파일을 직접 더블클릭하는 대신 Vite 서버를 사용해 주세요. WebGL2와 하드웨어 가속을 지원하는 브라우저가 필요합니다.
3D 모델과 목재·한지 텍스처는 코드에서 생성합니다. 외부 모델·이미지 파일은 필요하지 않습니다.
구글 웹폰트에 연결할 수 없을 때는 시스템 한글 글꼴로 표시됩니다.

## 조작

- 마우스 드래그 / 한 손가락 드래그: 시점 회전
- 마우스 휠 / 두 손가락 핀치 / 화면의 ＋·−: 확대·축소
- 집 모양 버튼: 카메라 초기화
- 밥그릇, 물그릇, 공, 방석, 책장, 장난감 상자, 창가 등을 클릭: 연결된 행동 실행
- 하단 행동 버튼: 열 가지 행동을 직접 선택. 키보드 Tab·Enter로도 사용 가능
- **자동 행동**: 켜면 행동이 끝난 뒤 다른 행동을 무작위 선택. 끄면 현재 행동을 끝낸 뒤 멈춤
- **잠시 멈춤 / 다시 시작**: 이동과 행동 애니메이션 정지·재개. 카메라는 계속 조작 가능
- 멈춘 상태에서 새 행동을 누르면 해당 행동으로 다시 시작
- 운영체제의 동작 줄이기 설정이 켜져 있으면 처음에는 일시 정지 상태

## 코드 구조

```text
src/
  main.js                         장면·조명·카메라·선택·프레임 루프·HMR 정리
  styles.css                      반응형 한글 UI
  character/Danbi.js               진돗개 모델과 부위별 애니메이션
  world/materials.js              공통 메시·재질·절차적 텍스처
  world/hanok.js                  한옥 건축·정원·돌담
  world/furniture.js              가구·클릭 대상·이동 장애물
  world/batchStatic.js            한옥의 정적 메시 병합
  behaviors/actions.js           열 가지 행동의 이름·목적지·시간
  behaviors/navigation.js        장애물 회피 A* 이동 경로·계단 높이
  behaviors/BehaviorController.js 행동 전환·자동 모드·일시 정지
  ui/UI.js                        한글 컨트롤과 상태 표시
tests/behavior.test.js            행동 및 경로 회귀 검사
docs/IMPLEMENTATION.md            구현 범위와 검증 기록
```

## 확장

새 가구는 `furniture.js`에서 만들고 `register(object, actionId, 한글이름)`으로 선택 대상으로 등록합니다.
통과하면 안 되는 가구는 `obstacle(x, z, 가로, 깊이)`로 등록합니다. 이동 경로에는 단비의 반경 여유가 더해집니다.
새 행동은 `actions.js`에 추가하고, 필요하면 `Danbi.animate`와 `BehaviorController.update`에 애니메이션을 추가합니다.
새 방을 추가할 때는 `hanok.js`의 공간과 `navigation.js`의 보행 영역·높이를 함께 확장해야 합니다.
`npm.cmd test`로 기존 행동의 경로와 상태 전환을 다시 확인하세요.

## 표현 방식

단비는 실시간 털 시뮬레이션을 쓰지 않고 둥근 크림색 메시와 볼의 털 뭉치로 복슬복슬한 인상을 표현합니다.
생활 한복 조끼, 노란 목수건, 삼각 귀, 동그란 눈과 말린 꼬리는 개별 메시입니다.
한옥은 캐릭터가 보이도록 앞벽과 앞쪽 지붕을 잘라낸 단면 디오라마이며, 뒤쪽 기와와 앞쪽 서까래를 남겼습니다.
이동은 바닥 높이를 따르는 경로 탐색이고, 공·정리 행동은 절차적 애니메이션입니다. 물리 엔진이나 저장 서버는 사용하지 않습니다.
