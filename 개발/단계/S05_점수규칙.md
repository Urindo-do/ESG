# S5. 점수 규칙 + 자동 테스트

| 예상 | 난이도 | 앞 단계 |
|---|---|---|
| 50분 | ★★☆ | S4 |

**끝나면**: 점수 계산·감소·하루 한도·결과 결정이 `rules.ts` 한 파일에 모이고, 자동 테스트가 전부 통과한다.

**왜 테스트?** 감소(48시간)와 한국시간 자정 같은 규칙은 틀려도 화면에서 **조용히** 넘어간다. 기대값을 코드로 박아 두면 나중에 고쳐도 바로 알 수 있다.

## 사람이 먼저 할 일

1. 받기 ([체크리스트 §2](../체크리스트.md#2-받기--매번-시작할-때))
2. Deno 설치 — **PowerShell** 창에서 한 줄 실행 후, 창을 새로 열어 `deno --version` 확인
   ```
   irm https://deno.land/install.ps1 | iex
   ```

## AI 지시

```text
[작업] 점수 규칙을 순수 함수로 만들고, 테스트를 먼저 써서 확인한다. (S5, 테스트 먼저)

[먼저 읽기] AGENTS.md, 개발/연결명세.md 의 §1(특히 §1-1 표), §3-1(result 6종과 처리 순서), §5(판정 JSON)

[만들 파일] supabase/functions/_shared/rules.ts, supabase/functions/_shared/rules.test.ts
1. rules.ts — 명세 §1의 상수 전부(이 파일이 원본)와 아래 순수 함수. 현재 시각은 함수 안에서 읽지 말고 인자로 받는다.
   - currentScore(storedScore, lastMissionAt, now) — §1-1 감소
   - applyPoints(currentScore, points) — 0~100으로 자르기
   - kstDayStart(now) — now가 속한 한국시간 날짜의 00:00을 UTC 시각으로
   - remainingToday(awardedCountsToday) — { meal, product, phrase } 남은 횟수
   - checkLimit(missionType, awardedCountsToday, totalCallsToday) — 한도 초과 여부
   - judgeMeal(llmJson), judgePhrase(llmJson) — result와 points (확신도 기준 포함)
   - judgeProduct(llmJson, candidates) — awarded / select_product / no_points / retake 와 확정된 후보 (자동 확정 기준 포함)
2. rules.test.ts — 아래 경우를 모두 넣는다.
   - §1-1 표: 47h 60, 48h 50, 71h 50, 72h 40, 96h 30, 30일 0
   - 상한·하한: 95+10=100, 0에서 감소해도 0
   - 한도: 빈 그릇 2회 인정 후 남은 1, 3회 인정 후 한도 초과, 0점 기록은 한도에 안 셈, 하루 전체 호출 30회면 한도 초과
   - 한국시간 경계: 2026-09-17T14:59:59Z는 9/17, 2026-09-17T15:00:00Z는 9/18
   - 확신도: 0.69면 retake, 0.70이면 판정대로
   - 제품: 1순위 0.65·2순위 0.50 → awarded / 1순위 0.65·2순위 0.60 → select_product / 후보 없음 → no_points / product_name이 null → retake

[순서]
① 테스트 파일과 "아무 일도 안 하는 빈 함수"만 먼저 만든다. 사람에게 deno test supabase/functions/_shared/ 실행을 요청해 **실패하는 것**을 보여 주고 멈춘다.
② 사람이 "계속"이라고 하면 함수를 채워 전부 통과시킨다.

[규칙] 이 두 파일 말고는 만들지 않는다. git 명령 실행 금지.

[끝나면] 테스트 결과(통과 개수)와 각 테스트가 무엇을 확인하는지 한 줄씩 알려주고 멈춘다.
```

## 확인

저장소 폴더에서:
```
deno test supabase/functions/_shared/
```
- [ ] ①에서 테스트가 **실패(빨강)** 하는 것을 직접 봤다 — 테스트가 정말 검사를 하고 있다는 뜻
- [ ] ②에서 전부 `ok` (통과)
- [ ] AI에게 "rules.ts 밖에 10, 48, 0.7 같은 규칙 숫자를 쓴 곳이 있는지 찾아줘" → 없다

## 막히면

- `deno`를 찾을 수 없음 → 창을 새로 열거나 컴퓨터 재시작 후 다시
- 테스트가 처음부터 통과함 → 함수가 비어 있지 않은 것. AI에게 "빈 함수로 되돌려 실패부터 보여줘"
