# S12. 3D 환경이 마을 — ✅ 완료 (9/17, 팀원이 완성해서 가져옴)

| 예상 | 난이도 | 앞 단계 |
|---|---|---|
| ~~120분~~ 0분 (이미 완료) | — | S1 |

**무슨 일이 있었나**: 3D 데이터 작업을 하던 팀원이 이 단계 전체(장면·캐릭터·상태 전환·자동 행동·클릭 행동·UI)를 직접 완성해서 가져왔다. Blender로 캐릭터('환경이')와 마을 에셋을 실제로 모델링·리깅했고, GLB로 내보내 `frontend/public/models/`에 있다. `node --test`로 11개 자동 검사, 헤드리스 크롬으로 화면 확인까지 되어 있었다(README 기록). ESG 저장소에도 반영했다.

기존 계획과 다르게 확정된 것 (자세한 이유는 [연결명세 §6 결정 기록](../연결명세.md#6-결정-기록)):

- 청결 5단계 → **3단계**(happy 70+ · 기본 30~69 · sad 30미만) + 점수에 따라 연속으로 진해지는 먼지·시듦 효과
- 캐릭터 디자인 → 새싹 후드 (기획서 콘셉트 이미지의 도토리 모자·나뭇가지 뿔이 아님)
- 파일 위치 → `frontend/src/village/`가 아니라 `frontend/src/` 바로 아래 (village.js, config.js, scene/, world/, character/, behaviors/, states/, ui/)
- 2D 대역 없음 ([S1](S01_프론트뼈대.md) 참고, 시연이 사전 녹화 영상이라 우선순위를 낮춤)

## 참고: 원래 계획이었던 2D→3D 전환 방식

<details>
<summary>펼치기 — 참고용, 이번 구현은 이 방식을 쓰지 않음</summary>

원래는 2D 대역이 먼저 있고, 이 단계에서 `village.js`의 `MODE`를 `'3d'`로 바꾸며 4단계(장면·상태연출·행동·UI)로 나눠 점진적으로 만들 계획이었다. 팀원이 처음부터 3D 전용으로 완성해서 가져와 이 순서를 따로 밟지 않았다.
