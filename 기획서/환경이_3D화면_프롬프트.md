# 환경이 3D 화면 제작 프롬프트

> 단비 프롬프트(Three.js + Vite, 한옥 속 아기 진돗개)의 구조를 그대로 두고 **환경이 서비스에 맞게 바꾼 버전**이다.
> 첨부할 것: 환경이 캐릭터 콘셉트 이미지 1장.
> 이 프롬프트는 **3D 화면만** 만든다. 로그인·카메라·AI 판정·점수 저장은 Supabase 쪽에서 처리하고, 3D 화면과는 아래 "연결 약속(API)"으로만 주고받는다.

## 단비 프롬프트에서 바뀐 것

| 항목 | 단비 | 환경이 |
|---|---|---|
| 주인공 | 아기 진돗개, 생활 한복 조끼 | 숲의 정령 '환경이' (첨부 이미지 기준) |
| 공간 | 미니 한옥 단면 디오라마 | 숲속 작은 마을 디오라마 (나무집·텃밭·개울) |
| 핵심 장치 | 없음 (생활 모습 감상) | **청결 점수 0~100에 따라 5단계로 외형·풍경이 바뀜** |
| 하단 버튼 | 밥 먹기·공놀이 등 행동 | **미션 3종 버튼** + 자동 행동 제어 |
| 외부 연결 | 없음 | 점수·남은 횟수를 받고, 미션 버튼 클릭을 밖으로 알림 |

---

## 프롬프트 (그대로 복사해서 사용)

```text
Three.js와 Vite를 사용해, 숲의 정령 캐릭터 **'환경이'**가 작은 숲속 마을에서 생활하는 인터랙티브 3D 웹 앱을 만들어줘.
이 화면은 환경 습관 앱 「환경이」의 홈 화면이다. 사용자의 청결 점수(0~100)에 따라 환경이와 마을의 모습이 달라지는 것이 핵심이다.

[캐릭터]
주인공은 사실적인 캐릭터가 아니라 동물의 숲처럼 친근한 2~3등신 데포르메 캐릭터다. 첨부한 콘셉트 이미지를 기준으로 만든다.
- 머리: 윤기 나는 도토리 껍데기 모자, 모자 위로 뻗은 나뭇가지 모양의 작은 뿔(끝에 새잎), 뾰족한 요정 귀
- 얼굴: 동그랗고 큰 갈색 눈, 발그레한 볼, 작은 코, 활짝 웃는 입
- 옷: 나뭇잎을 겹쳐 만든 초록 후드와 망토, 머리와 가슴의 작은 꽃 장식(분홍·보라·하늘색), 가슴에 '환경이' 이름표
- 소품: 씨앗이 든 가죽 크로스백, 작은 하늘색 물뿌리개, 손에 든 새싹 화분, 나무껍질 질감의 손, 갈색 부츠
- 이름표와 표지판의 글자는 반드시 '환경이'로 표기한다.

[공간]
따뜻한 숲속 작은 마을의 3D 디오라마로 구성한다. 한 화면에 자연스럽게 보이도록 배치한다.
- 큰 나무 둥치를 파서 만든 환경이의 나무집(둥근 문, 작은 창, 이끼 지붕)
- 작은 텃밭과 꽃밭, 돌길, 나무 벤치, 나무 그늘
- 오른쪽으로 흐르는 맑은 개울과 징검다리
- 나무 표지판 「자연과 함께! 환경이 마을」
- 색이 물든 가을 나무 몇 그루와 초록 나무, 떠다니는 나뭇잎과 나비
- 작은 나무 분리수거함 3칸(종이·플라스틱·캔) — 지금은 장식, 나중에 '쓰레기 버리기' 동작에 사용
소품: 물뿌리개, 씨앗 가방, 빗자루, 작은 삽, 새싹 화분, 도토리 바구니, 나무 우편함
빛: 따뜻한 오후 햇살, 나뭇잎 사이로 들어오는 부드러운 빛줄기, 은은한 환경광과 부드러운 그림자. 나무·이끼·돌·물의 질감을 살린다.

[청결 점수 5단계 — 가장 중요]
외부에서 받은 청결 점수에 따라 캐릭터와 마을이 부드럽게(1~2초) 전환된다. 구간 값은 설정 파일 한 곳에서 바꿀 수 있게 한다.
1. 반짝반짝 (80~100): 반짝이는 빛 입자, 꽃이 활짝 피고 나비가 많음, 맑은 하늘과 개울, 환경이가 신나서 폴짝 뜀
2. 깨끗 (60~79): 기본 모습, 밝은 표정
3. 보통 (40~59): 꽃이 조금 줄고 낙엽이 쌓이기 시작, 평온한 표정
4. 꼬질꼬질 (20~39): 옷과 볼에 먼지 얼룩, 바닥에 비닐봉지·캔 같은 쓰레기 몇 개, 꽃이 고개를 숙임, 하늘이 조금 흐려짐
5. 먼지투성이 (0~19): 캐릭터 주변에 먼지 구름 입자, 풀이 시들고 개울이 탁해짐, 환경이가 시무룩하게 앉아 있음
점수가 오를 때는 반짝이는 정화 효과(먼지가 흩어지고 꽃이 피어남)를 보여준다.

[자동 행동]
환경이는 마을을 돌아다니며 아래 행동을 무작위로 한다. 청결 단계에 따라 고르는 행동이 달라진다.
- 기본: 물뿌리개로 꽃에 물 주기, 텃밭에 씨앗 심기, 빗자루로 낙엽 쓸기, 나비 구경하기, 개울가 산책, 나무 그늘 벤치에서 낮잠, 표지판 닦기, 도토리 줍기
- 꼬질꼬질 이하: 시무룩하게 앉기, 몸의 먼지 털기, 쓰레기를 주워 분리수거함 쪽으로 가져가려다 멈칫하기
애니메이션: 귀 쫑긋, 뿔의 새잎 흔들림, 고개 갸웃, 손으로 물건 건드리기, 하품, 몸 털기, 졸면서 눈 감기, 점수를 얻었을 때 폴짝 뛰며 손 흔들기를 세심하게 넣는다.
물건을 클릭하면 그 물건에 맞는 행동을 직접 실행한다. (물뿌리개 → 물 주기, 씨앗 가방 → 씨앗 심기, 빗자루 → 낙엽 쓸기, 벤치 → 낮잠, 개울 → 산책)

[조작]
마우스 또는 터치로 시점을 자유롭게 회전하고 확대·축소한다. 자동 행동을 일시 정지하거나 다시 시작할 수 있다. 모바일 세로 화면을 우선으로 한다.

[UI]
UI는 전부 한글이며 게임 화면을 가리지 않게 단순하게 배치한다.
- 상단: 「환경이 마을」 제목, 청결 점수 게이지(0~100)와 현재 단계 이름(예: 「반짝반짝」), 오늘 남은 인증 횟수(빈 그릇 3 · 친환경 제품 2 · 환경 문구 10 형태)
- 하단 미션 버튼 3개: 「빈 그릇 인증」 「친환경 제품 인증」 「환경 문구 찾기」 — 남은 횟수가 0이면 흐리게 표시
- 보조 버튼: 「자동 행동」 켜기/끄기, 「잠시 멈춤」, 「다시 시작」, 「카메라 초기화」
- 점수를 얻으면 캐릭터 머리 위에 「+10」처럼 숫자가 떠오른다.
- 개발용 패널(개발 모드에서만 표시): 점수 슬라이더, 「시간 경과 테스트」 버튼
디자인: 둥근 카드, 부드러운 그림자, 연두·초록·크림·나무색 계열, 귀엽고 따뜻한 감성.

[그래픽]
둥근 형태, 귀여운 비율, 나무·이끼 질감, 물의 반짝임, 부드러운 환경광과 자연스러운 그림자를 중시한다. 지나치게 사실적인 스타일보다 아기자기한 3D 애니메이션 게임 느낌으로 만든다. 모바일에서도 부드럽게 돌아가도록 로우폴리 모델, 제한된 그림자 수, 픽셀 비율 상한(2)을 적용한다.

[연결 약속(API) — 반드시 지킬 것]
3D 화면은 로그인·카메라·AI·데이터 저장을 직접 처리하지 않는다. 아래 함수와 이벤트로만 바깥과 주고받는다.
- createVillage(container) → village 객체 반환
- village.setCleanliness(score)  // 0~100, 단계 전환 연출 포함
- village.setRemaining({ meal, product, phrase })  // 오늘 남은 인증 횟수 표시
- village.celebrate(points)  // 점수 획득 연출 (+points 표시, 정화 효과)
- village.onMissionSelect(callback)  // 미션 버튼 클릭 시 'meal' | 'product' | 'phrase' 전달
- village.dispose()
API 키나 비밀번호는 이 코드에 절대 넣지 않는다.

[코드 구조]
캐릭터, 마을 오브젝트, 행동, 청결 단계, UI를 모듈로 나눠 새 오브젝트·행동·단계를 쉽게 추가할 수 있게 한다.
src/
  main.js              // 개발용 실행 (가짜 점수로 동작 확인)
  village.js           // createVillage와 연결 약속(API)
  scene/               // 조명, 카메라, 지형, 개울
  character/           // 환경이 모델, 표정, 애니메이션
  props/               // 나무집, 텃밭, 벤치, 표지판, 분리수거함 등
  behaviors/           // 자동 행동과 클릭 행동
  states/cleanliness.js // 5단계 구간 값과 단계별 외형 설정
  ui/                  // 게이지, 미션 버튼, 보조 버튼, 개발용 패널
Vite 기반으로 로컬에서 바로 실행되고 Hot Module Replacement를 지원해야 한다.

전체 결과물은 단순한 3D 장면이 아니라, 사용자가 환경 실천을 하면 환경이와 마을이 눈에 띄게 깨끗해지고, 실천을 멈추면 조금씩 꼬질꼬질해지는 것이 느껴지는 귀엽고 인터랙티브한 생활형 3D 웹 앱으로 완성한다.
```

## 팀에서 연결할 때 참고

- 미션 버튼 → `onMissionSelect`로 받은 값에 맞춰 카메라 화면을 연다 (카메라·업로드는 3D 모듈 밖에서 구현).
- AI 판정과 점수 계산은 Supabase Edge Function에서 하고, 결과 점수를 받아 `setCleanliness`와 `celebrate`를 호출한다.
- 청결 구간(80/60/40/20)과 감소 규칙은 기획서 7장 점수 규칙 초안과 같은 값이다. 바꾸면 두 곳을 함께 고친다.
