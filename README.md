# 환경이 (ESG 해커톤 프로젝트)

EST AI Challengers 2기 해커톤 — 사진으로 환경 습관을 인증하면 캐릭터 '환경이'가 깨끗해지는 게임형 환경 습관 앱입니다.

## 프로젝트 소개

사용자가 일상 속 친환경 행동(빈 그릇 인증, 친환경 제품 구매, 환경 문구 찾기)을 사진으로 인증하면 포인트를 얻고, 그 포인트로 캐릭터 '환경이'와 마을의 상태(청결도 0~100)가 바뀝니다. 실천을 멈추면 시간이 지나면서 다시 지저분해집니다.

`frontend/`는 원래 S1(2D 대역)·S12(3D)에서 만들 예정이었는데, 3D 데이터 작업을 하던 팀원이 3D 마을 전체를 먼저 완성해서 가져왔습니다 (2026-09-17). 그래서 청결 단계는 5단계가 아니라 **3단계(happy/기본/sad)**로, 캐릭터 디자인도 새싹 후드로 바뀌었습니다 — 자세한 내용은 [`개발/연결명세.md`](개발/연결명세.md#6-결정-기록)와 [`frontend/README.md`](frontend/README.md) 참고.

## 기술 스택

- **Frontend**: Vite + 바닐라 JavaScript + Three.js (3D 마을 완성됨), Blender로 만든 GLB 캐릭터·마을 에셋
- **Backend / Infra**: Supabase (Auth — Google 로그인 기본·이메일은 테스트용, Postgres, Storage, Edge Functions)
- **AI**: 멀티모달 LLM API (사진 속 빈 그릇·제품·문구 판정)
- **Data**: Python + Pandas (공공데이터 인증 제품 전처리)
- **배포**: Vercel (S7)

## 규칙 요약 (전체는 [AGENTS.md](AGENTS.md))

1. **시작할 때 받기, 끝날 때 올리기.** 명령은 [체크리스트 §2·§3](개발/체크리스트.md#2-받기--매번-시작할-때)과 각 단계 파일에 그대로 있습니다.
2. **브랜치·PR 없이 `main`에 바로 올립니다.** 그래서 한 번에 한 단계씩만 올립니다.
3. **확인 항목을 전부 통과한 단계만 올립니다.** 체크(☑)는 직접 확인한 사람이 합니다.
4. **커밋 메시지는 `분류: 내용`** — `feat:` 기능 · `fix:` 수정 · `docs:` 문서 · `chore:` 설정·정리
5. **`.env.local`, API 키, 비밀번호는 절대 올리지 않습니다.** 프론트에는 Supabase 공개 키만, LLM 키는 Supabase 함수 비밀값으로만.
6. **명세와 코드가 다르면 명세(`개발/연결명세.md`)를 먼저 고칩니다.**
7. 막히면 단계 파일의 "막히면"을 보고, 현장 멘토님께 단계 파일과 오류 화면을 함께 보여 드립니다.
