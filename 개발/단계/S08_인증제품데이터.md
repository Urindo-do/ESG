# S8. 인증 제품 데이터

| 예상 | 난이도 | 앞 단계 |
|---|---|---|
| 50분 | ★★☆ | S7 |

**끝나면**: 공식 인증 제품 약 2,800개가 `eco_products` 표에 들어가고, `아이시스 eco 500ml`로 검색하면 시연 제품(인증번호 `2024-240`)이 1순위로 나온다.

## 사람이 먼저 할 일

1. 받기 ([체크리스트 §2](../체크리스트.md#2-받기--매번-시작할-때))
2. 파이썬 확인 — `python -c "import pandas, openpyxl"` 가 오류 없이 끝나야 한다. 오류가 나면:
   ```
   pip install pandas openpyxl
   ```
3. (선택) **환경표지 인증내역 csv** — 공공데이터포털의 해당 데이터 페이지에서 **이용허락범위**를 확인한다
   - 사용해도 되면 `data/raw/`에 넣고, `data/README.md` 출처 표에 적어 달라고 AI에게 함께 요청한다
   - 확인이 안 되면 **넣지 않는다** (환경성적표지만으로 시연 가능)
4. (선택, S9 준비) 시연 제품 사진을 LLM 제공사의 웹 화면에 올리고 "제품명과 용량을 읽어줘"라고 물어본다. 못 읽으면 S9에서 시연 제품을 바꾼다

## AI 지시

```text
[작업] 공공 인증 데이터를 eco_products 적재용 CSV로 만든다. (S8)

[먼저 읽기] AGENTS.md, data/README.md (파일 구조·열 위치·행 수), 개발/연결명세.md 의 §2-3 (컬럼, 검색용 이름 규칙과 예시 표)

[만들 파일] data/scripts/build_eco_products.py, data/processed/eco_products.csv (환경표지 csv를 넣었다면 data/README.md 출처 표의 그 줄도)
1. data/raw/의 환경성적표지 xlsx를 data/README.md의 열 위치로 읽는다 (6행이 머리글, 7행부터 데이터, 열 이름이 아니라 위치로).
2. cert_type = 영향범주 값 그대로(환경성적 / 저탄소제품), cert_no, company, product_name, valid_from, valid_to(YYYY-MM-DD), source = 원본 파일 이름.
3. valid_to가 한국시간 오늘보다 이전이면 뺀다.
4. search_name은 명세 §2-3 규칙으로 만든다. 스크립트 안에서 예시 표 4줄을 assert로 확인한다.
5. data/raw/에 환경표지 csv가 있으면 같은 컬럼으로 합친다 (cert_type = '환경표지'). 없으면 건너뛴다.
6. CSV 컬럼 순서는 cert_type,cert_no,company,product_name,search_name,valid_from,valid_to,source (id 없음), 인코딩 UTF-8.
7. 실행하면 전체 행 수, 뺀 행 수, cert_type별 행 수, '아이시스'가 들어간 행을 출력한다.

[규칙] data/raw/의 파일은 고치지 않는다. git 명령 실행 금지.

[끝나면] 실행 명령과 결과를 보여주고 멈춘다.
```

## AI가 끝난 뒤 사람이 할 일

1. 저장소 폴더에서 실행
   ```
   python data/scripts/build_eco_products.py
   ```
2. 대시보드 **Table Editor → eco_products → Insert → Import data from CSV** → `data/processed/eco_products.csv` 선택 → 컬럼이 맞는지 보고 가져오기

## 확인

- [ ] 출력의 유효 행 수가 **약 2,829** (9/17 기준, 날짜가 지나면 조금 줄 수 있음. 환경표지를 합쳤다면 그만큼 더 많음)
- [ ] 출력의 `2024-240` 행의 search_name이 `아이시스 eco 500ml pet`
- [ ] Table Editor의 `eco_products` 행 수가 출력 행 수와 같다
- [ ] SQL Editor에서 아래를 실행하면 1순위가 `2024-240`
  ```sql
  select * from search_eco_products('아이시스 eco 500ml', 5);
  ```
