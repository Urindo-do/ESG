# 환경이 (ESG 해커톤 프로젝트)

EST AI Challengers 2기 해커톤 — 사진으로 환경 습관을 인증하면 캐릭터 '환경이'가 깨끗해지는 게임형 환경 습관 앱입니다.

## 프로젝트 소개

사용자가 일상 속 친환경 행동(빈 그릇 인증, 친환경 제품 구매, 환경 문구 찾기)을 사진으로 인증하면 포인트를 얻고, 그 포인트로 캐릭터 '환경이'와 마을의 상태(청결도 0~100)가 바뀝니다. 실천을 멈추면 시간이 지나면서 다시 지저분해집니다.

## 폴더 구조

```
ESG/
└─ 기획서/
   ├─ 환경이_프로젝트기획서.hwp      # 해커톤 제출용 공식 기획서 (양식 채운 버전)
   ├─ 환경이_AI_아키텍처.png        # AI/서비스 아키텍처 다이어그램
   ├─ 환경이_3D화면_프롬프트.md      # 3D 홈 화면(캐릭터·마을) 제작용 프롬프트
   └─ 환경이_기획서_복붙용.md        # hwp 내용을 그대로 옮긴 마크다운 백업 (hwp가 안 열릴 때 대비)
```

앞으로 실제 구현이 시작되면 `frontend/`(Vite + Three.js), `supabase/`(DB·Auth·Edge Function) 같은 폴더가 추가될 예정입니다.

## 기술 스택

- **Frontend**: Vite + Three.js (환경이 마을 3D 홈 화면)
- **Backend / Infra**: Supabase (Auth, Postgres, Storage, Edge Functions)
- **AI**: 멀티모달 LLM API (사진 속 행동/제품/문구 판정)

## 협업 규칙 (꼭 지켜주세요)

1. **작업 시작 전에 `git pull`** — 남이 올린 내용이랑 충돌 안 나게 최신 상태부터 받고 시작합니다.
2. **브랜치 안 나누고 `main`에 바로 커밋합니다.** 해커톤 기간이 짧아서 단순하게 갑니다.
3. **커밋 메시지는 `분류: 내용` 형식으로 씁니다.**
   - `docs:` 기획서/문서 관련 (예: `docs: 기획서 초안 추가`)
   - `feat:` 새 기능 추가 (예: `feat: 로그인 화면 구현`)
   - `fix:` 버그 수정
   - `chore:` 설정, 자잘한 정리
4. **새 폴더를 만들면 이 README의 "폴더 구조"에도 같이 추가**해서, 나중에 들어오는 사람도 뭐가 어디 있는지 바로 알 수 있게 합니다.
5. **`.env`, API 키, 비밀번호 같은 민감한 값은 절대 커밋하지 않습니다.** (`.gitignore`에 이미 `.env`류는 제외되어 있습니다 — 그 규칙 안에서 작업해 주세요.)
6. **한글 파일명/폴더명 그대로 사용해도 됩니다** (`기획서/`처럼). 지금까지의 프로젝트 문서와 이름을 맞추기 위함입니다.
