# S0. 시작 준비

| 예상 | 난이도 | 앞 단계 |
|---|---|---|
| 40분 | ★☆☆ | 없음 |

**끝나면**: 개발에 필요한 계정·도구가 준비되고, 정해야 할 값이 확정되어 [연결 명세](../연결명세.md) 맨 위가 "확정"으로 바뀐다.

이 단계는 AI 없이 사람이 한다.

## 1. 도구 준비

[체크리스트 §4 준비물](../체크리스트.md#4-준비물-한-번만-확인) 표를 위에서부터 확인한다. 지금 당장 필요한 것은 Git · Git 이름·메일 · 저장소 쓰기 권한 · AI 코딩 도구 · Node.js다. 나머지는 해당 단계 전에 준비해도 된다.

Git 이름·메일이 비어 있으면 (명령 프롬프트, 따옴표 안을 자기 것으로 바꿔서):
```
git config --global user.name "홍길동"
git config --global user.email "me@example.com"
```

다른 사람이 이어받을 수도 있다면, 저장소 주인이 GitHub 저장소 **Settings → Collaborators** 에서 초대하고 받은 사람이 수락한다.

## 2. 정할 것

아래를 정하고 [연결 명세](../연결명세.md)에 반영한다 (직접 고치거나 AI에게 "연결 명세 §1을 이렇게 바꿔줘"라고 요청).

- [ ] 명세 §1의 `결정 필요` 7개 — 초안 값을 그대로 쓸지, 바꿀지
- [ ] LLM 제공사·모델 — 기준: 한글 글자 읽기, 이미지 입력, JSON 출력 고정 기능, 가격·무료 한도, 속도. **이미 키가 있는 제공사를 우선** (오늘 밤 결제·승인 대기 위험)
- [ ] 캐릭터 이름 — **환경이** 또는 콘셉트 이미지 속 **지구별이**
- [ ] 다 정했으면 명세 맨 위 `**상태: 초안.**` 을 `**상태: 확정 (9/17)**` 로 바꾸고, 명세 §6 결정 기록에 LLM 제공사와 캐릭터 이름을 한 줄씩 적는다

## 3. 확인할 것

- [ ] 운영진·멘토님께 **최종 시연 시각과 방식**(발표 시간, 노트북 화면인지 휴대폰 미러링인지) 확인 → [체크리스트 §5](../체크리스트.md#5-시간) 표에 적기
- [ ] `기획서/환경이_프로젝트기획서.hwp`를 한글 프로그램으로 열어 깨지지 않는지 확인 (깨지면 `기획서/환경이_기획서_복붙용.md`로 다시 옮겨 적기)

## 4. 계정

- [ ] **Supabase** — 새 프로젝트 만들기 (지역은 서울 근처 권장). 데이터베이스 비밀번호는 따로 안전하게 보관 (저장소·단톡에 적지 않음)
- [ ] 프로젝트 화면의 **Connect** 버튼 또는 **Project Settings**에서 아래 두 값을 찾아 메모 (S3에서 사용)
  - Project URL
  - 공개 키: `sb_publishable_…` (없으면 legacy `anon` 키)
  - ⚠️ `sb_secret_…` · `service_role` 키는 **어디에도 복사하지 않는다**
- [ ] **LLM API 키** — 발급하고 결제 수단·무료 한도 확인. 키는 S6에서 Supabase 비밀값으로만 넣는다 (저장소·AI 대화창에 붙여넣지 않음)

## 확인

- [ ] 준비물 중 Git · Node.js · AI 코딩 도구가 동작한다
- [ ] 연결 명세가 "확정"이다
- [ ] 시연 시각을 체크리스트에 적었다
- [ ] Supabase 대시보드에 들어가지고, URL·공개 키를 메모했다
- [ ] LLM 키가 있다

## 올리기

```
git status
git add 개발/연결명세.md 개발/체크리스트.md
git commit -m "docs: S0 결정 사항 확정"
git pull --rebase
git push
```

## 막히면

- `git push`에서 권한 오류(403) → 저장소 Collaborator 초대를 수락했는지 확인
- 첫 push 때 GitHub 로그인 창이 뜨면 로그인한다
