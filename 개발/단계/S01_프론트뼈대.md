# S1. 프론트 뼈대 + 2D 대역 마을

| 예상 | 난이도 | 앞 단계 |
|---|---|---|
| 40분 | ★☆☆ | S0 |

**끝나면**: `npm run dev`로 앱 첫 화면과 마을 연습 페이지가 뜨고, 연습 페이지의 점수 슬라이더로 청결 5단계 이름이 바뀐다.

**왜 2D 대역부터?** 3D 마을(S12)은 오래 걸린다. 같은 약속(API)을 가진 간단한 2D 마을을 먼저 두면 앞 단계들이 3D를 기다리지 않고, 3D가 실패해도 이것으로 시연할 수 있다.

## 사람이 먼저 할 일

- `node -v`가 22.12 이상인지 확인
- [체크리스트 §2](../체크리스트.md#2-받기--매번-시작할-때)로 받기

## AI 지시

```text
[작업] 환경이 앱의 프론트엔드 뼈대와 "2D 대역 마을"을 만든다. (S1)

[먼저 읽기]
- AGENTS.md
- 개발/연결명세.md 의 §0-1(파일 위치·환경변수), §1(청결 5단계), §4(마을 API)
- reference/danbi-hanok-day/ 의 package.json, vite.config.js, index.html (프로젝트 구성 참고용, 수정 금지)

[만들거나 고칠 파일] frontend/ 아래만
1. frontend/package.json — reference와 같은 구성(type module, scripts의 dev·build·preview). 의존성은 three(reference와 같은 버전)와 @supabase/supabase-js, 개발 의존성은 vite(reference와 같은 버전). 다 쓰면 frontend 폴더에서 npm install 을 실행한다.
2. frontend/vite.config.js — reference와 같게.
3. frontend/.env.example — 명세 §0-1의 환경변수 이름 두 줄, 값은 비워 둔다.
4. frontend/index.html + frontend/src/main.js — 제목 "환경이", #village 영역에 마을을 띄우고 점수 50을 넣는다. (// 임시: S3에서 로그인·실제 점수로 교체)
5. frontend/src/village/states/cleanliness.js — 명세 §1의 청결 5단계 경계값과 이름. 경계값은 이 파일에만 둔다.
6. frontend/src/village/village2d.js — 명세 §4의 API 6개를 HTML/CSS만으로 구현한다.
   - 위: "환경이 마을" 제목, 점수 게이지(0~100)와 단계 이름, 오늘 남은 횟수(빈 그릇·친환경 제품·환경 문구)
   - 가운데: 단계마다 배경색과 표정(이모지)이 달라지는 간단한 캐릭터 자리
   - 아래: 미션 버튼 3개 「빈 그릇 인증」「친환경 제품 인증」「환경 문구 찾기」 — 남은 횟수가 0이면 흐리게, 누르면 onMissionSelect 콜백에 'meal' | 'product' | 'phrase'
   - celebrate(points) — "+points"가 캐릭터 위로 떠올랐다 사라짐
7. frontend/src/village/village.js — 맨 위에 const MODE = '2d'; createVillage(container)는 MODE에 따라 마을을 돌려준다. (3D는 S12에서 추가)
8. frontend/village-dev.html + frontend/src/village/dev.js — 마을 연습용 페이지: 점수 슬라이더(0~100), 남은 횟수 입력 3개, 「celebrate +10」 버튼, 미션 버튼을 누르면 받은 값을 화면에 표시.

[규칙]
- 로그인·카메라·Supabase 연결은 아직 만들지 않는다 (S3, S4).
- UI 문구는 한글, 휴대폰 세로 화면 우선.
- git 명령은 실행하지 않는다.

[끝나면] 만든 파일 목록, npm run dev 실행 방법, 확인할 주소 2개를 알려주고 멈춘다.
```

## 확인

`frontend` 폴더에서 `npm run dev` → 터미널에 나온 주소(보통 `http://localhost:5173/`)를 연다. 끝낼 때는 터미널에서 `Ctrl + C`.

- [ ] 첫 주소에서 "환경이" 화면, 점수 50 · 단계 '보통'
- [ ] 주소 끝에 `village-dev.html`을 붙인 연습 페이지에서, 슬라이더를 19↔20, 39↔40, 59↔60, 79↔80으로 움직이면 단계 이름이 바뀐다
- [ ] 미션 버튼 3개를 누르면 `meal` / `product` / `phrase`가 표시된다
- [ ] 남은 횟수를 0으로 하면 그 버튼이 흐려진다
- [ ] 「celebrate +10」을 누르면 +10이 떠오른다
- [ ] `git status`에 `node_modules`가 보이지 않는다
